## Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/asuarezaliano/KalosFront.git
cd kalos-frontend
```

2. Instala las dependencias:
```bash
npm install
# o
yarn install
# o
pnpm install
```

## Iniciar el Proyecto

### Modo Desarrollo

Para iniciar el servidor de desarrollo:

```bash
npm run dev
# o
yarn dev
# o
pnpm dev
# o
bun dev
```

El proyecto estará disponible en [http://localhost:3000](http://localhost:3000).


## Estructura del Proyecto
